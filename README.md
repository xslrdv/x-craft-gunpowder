# 💣 X Craft Gunpowder

A vanilla-friendly **Minecraft** mod for **NeoForge** that introduces an alternative, practical way to craft *gunpowder* using early-game processing and basic resources.

---

## ✨ Features

* **Flint Extraction**
  * Extract *Flint* from a *Gravel block* using a *Bucket of Water*.
* **Flint Dust**
  * Obtain *dust* by crushing *Flint* using a *Pickaxe*.
* **Coal Dust**
  * Obtain *dust* by crushing *Coal* or *Charcoal* using a *Pickaxe*.
* **Gunpowder Crafting**
  * Combine **Flint Dust**, **Coal Dust**, and *Redstone Dust* to craft *Gunpowder*.
  * Eliminates sole reliance on Creeper hunting or mob farms for early-game explosives and fireworks.

---

## 💡 Why Fried Egg?

* **Alternative Progression**: Provides a peaceful and tactical way to farm *gunpowder* without requiring aggressive mob hunting.
* **Intuitive Mechanics**: Uses immersive interactions (washing gravel, crushing resources with tools) that fit naturally into vanilla gameplay.
* **Vanilla-Friendly**: Vanilla-Friendly: Keeps recipe balance fair without adding unneeded bloat or complex machinery.

---

## 🛠️ Installation & Requirements

### Requirements
1. **Minecraft**: `26.3`
2. Mod Loader: **NeoForge** `26.3.0.95+`

### Installation
1. Download and install **NeoForge** (version `26.3.0.95` or higher) for **Minecraft** `26.3`.
2. Download the latest release of **X Craft Gunpowder**.
3. Place the `.jar` file into your `.minecraft/mods` folder.
4. Launch the game and enjoy!
