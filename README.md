# 💣 X Craft Gunpowder

A vanilla-friendly **Minecraft** mod for **NeoForge** that introduces an alternative, balanced, and practical way to craft *Gunpowder* using early- and mid-game processing and basic resources.
As well as reliable methods to extract *Flint* from *Gravel* by washing it with *water* or sifting it with a *shovel*.

---

## ✨ Features

* **Raw Gunpowder**
  - Combine *Flint*, *Coal* or *Charcoal*, *Bone Meal*, and a *Pickaxe* to craft *Raw Gunpowder* (x4) (consumes tool durability).
  - Dry *Raw Gunpowder* in a *Furnace*, *Smoker*, or *Blast Furnace* to obtain *Gunpowder*.
* **Instant Gunpowder**
  - Combine *Flint*, *Coal* or *Charcoal*, *Redstone Dust*, and a *Pickaxe* to craft *Gunpowder* (x3) directly without drying (consumes tool durability).
* **Flint Extraction**
  - Wash *Gravel* with a *Water Bucket* to extract *Flint* (x4) *(returns an empty bucket)*.
  - Sift *Gravel* with a *Shovel* to extract *Flint* (x1) *(consumes tool durability)*.

---

## 💡 Why X Craft Gunpowder?

- **Vanilla-Friendly & Balanced**: Carefully tuned recipes that respect survival progression without adding unnecessary clutter.
- **Fair Resource Trade-off**: Uses tool durability, drying steps, and water washing, making *Gunpowder* and *Flint* production earned, not given.
- **Alternative Progression**: Provides a peaceful, tactical way to obtain *Gunpowder* without relying solely on aggressive mob hunting.
- **Intuitive Mechanics**: Uses immersive interactions (*washing and sifting gravel*, *crushing and drying ingredients*) that fit naturally into vanilla gameplay.

## 🛠️ Installation & Requirements

### Requirements
1. **Minecraft**: `26.3`
2. Mod Loader: **NeoForge** `26.3.0.95+`

### Installation
1. Download and install **NeoForge** (version `26.3.0.95` or higher) for **Minecraft** `26.3`.
2. Download the latest release of **X Craft Gunpowder**.
3. Place the `.jar` file into your `.minecraft/mods` folder.
4. Launch the game and enjoy!
